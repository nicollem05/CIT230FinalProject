CIT230 Database Final Project
This project demonstrates SQL proficiency through the design of a custom relational database and the execution of advanced data queries.

Key Features:

Custom Schema: Creation of an academic system with tables for Courses, Students, Status, and Majors.

Data Analysis (Sakila): Practical implementation of JOIN operations, aggregate functions, and rental management logic.

Geographical Queries (World): Data retrieval using pattern matching (LIKE), ranges (BETWEEN), and pagination (OFFSET).

Relational Integrity: Implementation of primary keys and structured data relationships.

Usage: The script is intended for MySQL environments. It first initializes the CIT230FinalProject database before switching contexts to perform analytical queries on standard sample databases.
